## Step 3: Post-Cleanup Verification

After ALL cleanup tasks complete:

```bash
cd /home/beagle/work/brummer

# 1. Verify clean build
echo "🔨 Building..."
go build ./cmd/brum
if [ $? -eq 0 ]; then
    echo "✅ Build passes"
else
    echo "❌ Build failed - investigate immediately"
    exit 1
fi

# 2. Run all unit tests
echo "🧪 Running unit tests..."
go test ./internal/tui/...
if [ $? -eq 0 ]; then
    echo "✅ Unit tests pass"
else
    echo "❌ Unit tests failed - investigate immediately"
    exit 1
fi

# 3. Run integration tests
echo "🔗 Running integration tests..."
go test -tags=integration ./test/integration/...
if [ $? -eq 0 ]; then
    echo "✅ Integration tests pass"
else
    echo "❌ Integration tests failed - investigate immediately"
    exit 1
fi

# 4. Verify test coverage
echo "📊 Checking test coverage..."
COVERAGE=$(go test -cover ./internal/tui/... 2>&1 | grep -oP 'coverage: \K[0-9.]+')
echo "Coverage: ${COVERAGE}%"
if (( $(echo "$COVERAGE >= 87" | bc -l) )); then
    echo "✅ Coverage ≥87%"
else
    echo "❌ Coverage below 87% - investigate"
    exit 1
fi

# 5. Run race detection
echo "🏃 Running race detection..."
make test-race
if [ $? -eq 0 ]; then
    echo "✅ No race conditions detected"
else
    echo "❌ Race conditions detected - investigate immediately"
    exit 1
fi

# 6. Check for linting errors
echo "🔍 Running linter..."
golangci-lint run internal/tui/...
if [ $? -eq 0 ]; then
    echo "✅ No linting errors"
else
    echo "⚠️  Linting issues found - review"
fi
```

**Expected**: All checks pass ✅

## Troubleshooting

**Build fails after cleanup**:
```bash
# Check what broke
go build -v ./cmd/brum 2>&1 | grep error

# Review recent changes
git diff HEAD~1

# If necessary, revert last cleanup commit
git revert HEAD
```

**Tests fail after cleanup**:
```bash
# Run tests verbosely to see failure
go test -v ./internal/tui/... 2>&1 | grep FAIL

# Check for removed code that was still referenced
git grep "function_name_that_was_removed"
```

**Coverage dropped**:
```bash
# See which packages lost coverage
go test -cover ./internal/tui/...

# May need to update tests for consolidated code
```
